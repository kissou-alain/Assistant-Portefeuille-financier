# Archives : versions antérieures du projet

Ce dossier conserve, pour l'historique, les versions précédentes des livrables. **Elles ne sont pas à évaluer** : les livrables finaux (version 4) sont listés dans le [README principal](../README.md).

| Dossier | Contenu |
|---|---|
| `rapport_v1/` | Premier rapport (Word), première présentation PowerPoint et premier script de la vidéo (version 1, avant la refonte) |
| `notebooks/` | Notebook de la version 1 et sauvegardes des versions 1 à 3 |
| `application_streamlit_v1/` | Première interface (Streamlit), remplacée par l'application web (`api/` + `web/`). Toujours exécutable : `.venv\Scripts\streamlit.exe run archives/application_streamlit_v1/streamlit_app.py` |
| `docs/` | Plan de la refonte de la version 1 vers la version 4 |
| `captures_originales/` | Captures d'écran d'origine de l'application ; le rapport utilise leurs versions recadrées (`reports/rapport/images/capture_*.png`) |
